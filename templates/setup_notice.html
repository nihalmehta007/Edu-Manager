Quick 3-Step MongoDB Atlas Setup:

1
Get MongoDB Atlas Connection String
Create a free MongoDB database at mongodb.com/atlas. Click Connect > Drivers and copy the URI. mongodb+srv://<username>:<password>@cluster0.xxx.mongodb.net/edumanage?retryWrites=true&w=majority
2
Whitelist All IP Addresses in MongoDB Atlas
In Atlas, go to Network Access → Add IP Address → select Allow Access From Anywhere (0.0.0.0/0). This allows Vercel serverless functions to connect.
3
Add Environment Variables in Vercel
In your Vercel Project Dashboard → Settings → Environment Variables, add:
• Key: MONGO_URI | Value: your_atlas_connection_string
• Key: SECRET_KEY | Value: any_random_secret_string
